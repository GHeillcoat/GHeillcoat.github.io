Agent 不是万能的。2026 年，以下五个问题仍然是核心挑战：

**幻觉（Hallucination）**：工具返回了正确结果，但 Agent 误读了。比如天气 API 返回 `{"rain": 0.2}`（20% 降水概率），Agent 却解读为"确定下雨"。更隐蔽的幻觉：Agent 把不同工具返回的信息"脑补"成了不存在的关系——"A 公司 Q2 营收增长 15%"和"A 公司 Q2 发布了新产品"被 Agent 合成"新产品推动营收增长 15%"，但原文没有因果关系。

**死循环（Infinite Loop）**：Think-Act 无止境。Agent 在"想 -> 做 -> 不满意 -> 再想 -> 再做"中无限循环，特别是当它对自己的输出永远不满意时。典型表现：连续 10 次调用同一个搜索工具，每次只改一个标点符号。2026 年的缓解方案：硬限制最大步数（30 步）+ 循环检测（连续 3 次相同工具+相同参数 -> 强制终止）。

**工具滥用（Tool Overuse）**：简单问题也调用复杂工具链。用户问"今天几号"，Agent 调用搜索引擎、时间 API、日历工具——三个工具回答一个不需要工具的问题。每次不必要的工具调用都增加延迟和成本。

**成本（Cost）**：每次 Think-Act 循环都调用 LLM，复杂任务可能 20-50 轮。以 Claude Sonnet 4.6 为例，2026 年一个复杂 Agent 任务（如"分析这份 50 页的报告并写摘要"）的 API 成本在 $0.5-$5 之间。如果任务需要反复重试，成本翻倍。企业级 Agent 部署需要精心设计"早停"策略——任务基本完成时就停止，不要追求完美。

**安全（Safety）**：Agent 拥有工具调用能力，如果不加限制可能执行危险操作。删除文件、发送敏感数据到外部 API、修改生产环境配置——这些都需要权限控制。2026 年的最佳实践：工具分级（只读工具自动执行，写入工具需要确认），操作审计（所有工具调用记录日志），人工审批（高风险操作必须人确认）。
