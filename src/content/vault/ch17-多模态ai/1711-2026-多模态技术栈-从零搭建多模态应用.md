### 17.11.1 选型指南

| 需求 | 推荐方案 | 说明 |
|------|---------|------|
| 图文理解（通用） | GPT-5.5 / Gemini 3.5 Pro API | 调用 API，不需要自己部署 |
| 图文理解（开源/私有化） | Qwen-VL / LLaVA-NeXT | 本地部署，数据不出域 |
| 图像生成 | Stable Diffusion 4 / Flux 2 | 开源，可控性强 |
| 视频理解 | Gemini 3.5 Pro / Video-LLaMA | 长视频场景 |
| 视频生成 | Runway Gen-4 / Kling 2 API | 商业化产品，效果好 |
| 语音识别 | Whisper v4 | 开源，多语言，效果好 |
| 语音合成 | ElevenLabs API / ChatTTS | 商业/开源可选 |
| 语音对话 | GPT-5.5 实时语音 API | 全双工，低延迟 |
| 端侧多模态 | MiniCPM-V + Whisper-tiny | 手机上运行 |
| 文档理解 | Qwen-VL / GPT-5.5 | 中文文档优先 Qwen-VL |

### 17.11.2 从零搭建多模态应用的步骤

**第一步：明确模态需求**
- 输入：文字？图片？语音？视频？多模态混合？
- 输出：文字？图片？语音？动作？
- 延迟要求：实时（<300ms）？准实时（<5s）？离线（分钟级）？

**第二步：选择模型架构**
- 简单图文问答 → 调用 GPT-5.5 API（最省事）
- 复杂视觉理解（细粒度定位）→ CogVLM / InternVL
- 需要私有化部署 → Qwen-VL / LLaVA-NeXT
- 需要端侧运行 → MiniCPM-V

**第三步：构建多模态数据处理流水线**
- 图片预处理：缩放、裁剪、格式转换（PIL/OpenCV）
- 视频预处理：抽帧（关键帧提取）、降采样、音频分离（FFmpeg）
- 语音预处理：降噪、VAD（语音活动检测）、分段（Whisper/WebRTC VAD）
- 文本预处理：tokenization、截断、拼接

**第四步：实现多模态交互逻辑**
- 单轮：用户输入 → 模型处理 → 返回结果
- 多轮对话：维护对话历史（包括图片、语音的引用）
- 流式输出：逐 token 返回，提升用户体验
- 错误处理：模态缺失、模型超时、格式不支持

**第五步：部署与优化**
- API 服务化：FastAPI/Flask 封装模型为 REST API
- 推理优化：vLLM（LLM 推理加速）、TensorRT（CNN 推理加速）、量化（INT8/INT4，INT8 将模型参数从 32 位浮点压缩到 8 位整数，推理速度提升 2-3 倍，精度损失 < 1%）
- 缓存策略：相似图片的 embedding 可以缓存复用
- 负载均衡：多模型实例并行处理请求

**第六步：评估与迭代**
- 图文理解：人工评估（相关性、准确性、幻觉率）
- 图像生成：FID（Fréchet Inception Distance，衡量生成图片和真实图片分布的距离）、CLIP Score（衡量生成图片和文字描述的对齐程度）、人工偏好
- 语音：WER（Word Error Rate，词错误率）、MOS（Mean Opinion Score，主观评分）
- 持续收集用户反馈，迭代优化
