> 英文术语 → 中文翻译 + 一句话解释。阅读笔记时遇到英文词，来这查。

## 基础概念

| 英文 | 中文 | 一句话 |
|------|------|--------|
| AI / Artificial Intelligence | 人工智能 | 让计算机模仿人类智能的技术 |
| ML / Machine Learning | 机器学习 | AI 的一个分支，让计算机从数据中学习 |
| DL / Deep Learning | 深度学习 | 用多层神经网络做机器学习 |
| LLM / Large Language Model | 大语言模型 | 用海量文本训练的巨型神经网络 |
| AGI / Artificial General Intelligence | 通用人工智能 | 能在任何任务上达到人类水平的人工智能 |

## 架构

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Transformer | 变换器（不翻译） | 现代 AI 的底层架构，核心是自注意力 |
| Attention | 注意力机制 | 让模型"关注"输入中重要的部分 |
| Self-Attention | 自注意力 | 序列中每个词互相对比，找出关联 |
| Encoder | 编码器 | 把输入"理解"成内部表示 |
| Decoder | 解码器 | 把内部表示"翻译"成输出 |
| FFN / Feed-Forward Network | 前馈网络 | Transformer 中的"知识存储"层 |
| Embedding | 嵌入 / 向量化 | 把文字变成一串数字 |
| Token | 词元 / 令牌 | 模型处理的最小文本单位 |
| Tokenizer | 分词器 | 把文本切分成 token 的工具 |

## 训练

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Fine-tuning | 微调 | 在预训练模型上用自己的数据继续训练 |
| SFT / Supervised Fine-Tuning | 监督微调 | 用"问题-答案"对教模型对话 |
| RLHF | 人类反馈强化学习 | 让人类打分来训练模型 |
| DPO / Direct Preference Optimization | 直接偏好优化 | 不需要奖励模型的简化版 RLHF |
| LoRA | 低秩适配 | 只训练小补丁，不改变原模型 |
| QLoRA | 量化低秩适配 | LoRA + 4-bit 量化，更省显存 |
| PEFT | 参数高效微调 | 只微调少量参数的技术总称 |
| Pre-training | 预训练 | 在海量数据上的初始训练 |
| Epoch | 轮次 | 模型把全部数据学完一遍 |
| Batch Size | 批次大小 | 每次训练用多少条数据 |
| Learning Rate | 学习率 | 每次参数调整的步长 |

## 推理与部署

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Inference | 推理 | 模型生成答案的过程 |
| Quantization | 量化 | 用更少的比特表示权重，压缩模型 |
| GGUF | GGUF 格式 | llama.cpp 使用的模型文件格式 |
| vLLM | vLLM 引擎 | 高性能 LLM 推理框架 |
| Ollama | Ollama 工具 | 一键在本地跑大模型 |
| Latency | 延迟 | 从提问到收到第一个字的时间 |
| Throughput | 吞吐量 | 每秒能处理多少个请求 |

## RAG

| 英文 | 中文 | 一句话 |
|------|------|--------|
| RAG / Retrieval-Augmented Generation | 检索增强生成 | 先搜资料，再让 AI 根据资料回答 |
| Chunking | 分块 | 把长文档切小段，方便检索 |
| Vector Database | 向量数据库 | 存储和搜索向量（数字串）的数据库 |
| BM25 | BM25 算法 | 传统关键词搜索算法 |
| Reranking | 重排序 | 对初步检索结果精排，挑最相关的 |
| Semantic Search | 语义搜索 | 按含义搜索，不是按关键词 |

## Agent

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Agent | 智能体 / 代理 | 能自主使用工具完成任务的 AI |
| ReAct | 推理-行动循环 | Agent 的思考→行动→观察循环 |
| Function Calling | 函数调用 | 让 LLM 能调用外部 API/工具 |
| Tool Use | 工具使用 | Agent 调用外部工具的能力 |
| MCP / Model Context Protocol | 模型上下文协议 | AI 连接工具的通用接口标准 |
| A2A / Agent-to-Agent | Agent 间通信协议 | Agent 之间对话的标准协议 |
| Multi-Agent | 多智能体 | 多个 Agent 协同工作 |

## 多模态

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Multimodal | 多模态 | 同时处理文字、图片、声音等多种信息 |
| VLM / Vision Language Model | 视觉语言模型 | 能"看图说话"的 AI |
| CLIP | CLIP 模型 | 把图片和文字映射到同一个向量空间 |
| ViT / Vision Transformer | 视觉 Transformer | 用 Transformer 处理图像 |
| Diffusion Model | 扩散模型 | 从噪声中逐步"还原"出图像的生成模型 |
| TTS / Text-to-Speech | 文字转语音 | 把文字变成语音 |

## 评估

| 英文 | 中文 | 一句话 |
|------|------|--------|
| Benchmark | 基准测试 | 标准化的模型能力测试 |
| Hallucination | 幻觉 | 模型编造事实 |
| Ground Truth | 真实答案 | 人工标注的正确结果 |
| Precision | 精确率 | 预测为正的样本中多少是真的 |
| Recall | 召回率 | 真正的正样本中多少被找到了 |
| F1 Score | F1 分数 | 精确率和召回率的调和平均 |
