传统机器学习中，特征工程是"手工活"——数据科学家花 70% 的时间洗数据、造特征、选特征。2026 年，AutoML（自动机器学习）工具正在改变这个局面，但理解其能力和局限至关重要。

### 5.8.1 主流 AutoML 工具对比

**AutoGluon**（AWS 开源，2020 年发布）：
- 核心能力：自动特征工程、自动模型选择、自动超参数调优、自动集成
- 独特优势：多层 stacking（堆叠集成）——多个模型的预测作为新特征输入到元模型，自动找到最优的模型组合；支持文本、图像、表格数据
- 使用方式：`from autogluon.tabular import TabularPredictor; predictor = TabularPredictor(label='target').fit(train_data)` —— 一行代码完成全流程
- 适用场景：表格数据的快速建模；需要多模型集成效果最优时
- 局限：训练时间较长（因为要尝试多种模型）；黑盒，不易解释

**H2O AutoML**（H2O.ai，Java 核心 + Python/R 接口）：
- 核心能力：自动特征工程、自动模型选择、自动超参数调优、自动集成
- 独特优势：分布式计算，可处理大数据；提供详细的模型排行榜和可解释性报告
- 适用场景：企业级大规模数据的自动化建模；需要分布式计算时
- 局限：内存消耗大（Java 核心）；对文本和图像数据支持不如 AutoGluon

**PyCaret**（开源，基于 Scikit-learn 的封装）：
- 核心能力：自动化整个 ML 工作流——数据预处理、特征工程、模型训练、模型选择、模型部署
- 独特优势：低代码，API 极其简洁；内置 20+ 种预处理和特征工程技术；自动生成模型对比报告
- 使用方式：`from pycaret.classification import *; setup(data, target='target'); compare_models()` —— 几行代码完成全流程
- 适用场景：快速原型验证；教学和学习；小到中型数据集
- 局限：对超大数据的支持有限；定制化空间小

**AutoSklearn**（基于 Scikit-learn + AutoML 元学习）：
- 核心能力：元学习（Meta-Learning）——根据数据集的元特征自动选择最可能有效的模型和超参数
- 独特优势：贝叶斯优化 + 元学习，比纯贝叶斯优化更高效；可以 warm-start（从之前的实验中学习）
- 适用场景：需要可复现的 AutoML 研究；对小数据集的快速建模

**Featuretools**（自动化特征工程专业工具）：
- 核心能力：深度特征合成（Deep Feature Synthesis）——自动从关系型数据（多张表）中生成特征
- 独特优势：自动理解表之间的关系（外键、时间关系），自动生成聚合特征（如"用户过去 7 天的平均消费"）、变换特征（如"年龄的对数"）
- 适用场景：关系型数据库的特征工程；多表关联数据的特征提取
- 局限：只做特征工程，不做模型训练；需要明确的表关系定义

### 5.8.2 什么时候用 AutoML，什么时候手工做特征工程

**AutoML 擅长的场景**：
- 表格数据的快速基线建模——你不知道哪种模型最好，AutoML 自动帮你试
- 特征数量多（100+）且你不确定哪些有用——自动特征选择
- 需要在多个模型之间公平比较——AutoML 统一了预处理和评估流程
- 你刚开始一个项目，需要快速验证"这个问题是否可解"——AutoML 给出天花板

**AutoML 不擅长的场景**：
- 需要业务理解来创造特征——AutoML 不会知道"用户最近 7 天的登录次数"比"用户总登录次数"更有预测力
- 数据有明确的领域结构（如时间序列、地理空间、网络图）——需要手工设计专门的特征
- 需要极端可解释性——AutoML 的集成模型通常是黑盒，SHAP 值可以帮助解释但不能完全替代手工建模
- 深度学习场景（图像、文本、语音）——AutoML 在 CV 和 NLP 领域的自动架构搜索（NAS）还处于研究阶段，远不如手工设计的 ResNet、ViT、GPT 等架构
- 数据量极大（TB 级）——AutoML 的训练开销太大，手工设计一个简单模型可能更实际

### 5.8.3 2026 年特征工程的实践建议

**传统机器学习（表格数据）**：
1. 先用 PyCaret 或 AutoGluon 跑一个基线，了解"这个问题的天花板在哪"
2. 分析 AutoML 的特征重要性报告，理解哪些特征在起作用
3. 基于业务理解，手工创造 AutoML 不会想到的特征（如领域特定的比率、时间窗口聚合）
4. 把手工特征加入 AutoML，看性能是否提升
5. 最终模型可以选择 AutoML 的集成模型，也可以选择你手工优化后的单一模型

**深度学习（图像、文本）**：
1. 特征工程主要由模型自动完成（CNN 学习图像特征，Transformer 学习文本特征）
2. 你的精力应该放在数据增强（图像翻转、文本改写）和预处理（文本清洗、图像归一化）上
3. 特征工程的角色从"手工设计特征"转变为"设计数据增强策略和预训练任务"

**2026 年的核心原则**：理解特征工程的基本原理（本章的内容），用 AutoML 加速重复劳动，把创造力留给"造什么特征有意义"这个只有你能回答的问题。你的价值不在于"手工比 AutoML 做得更好"，而在于"知道 AutoML 没考虑到什么"。
