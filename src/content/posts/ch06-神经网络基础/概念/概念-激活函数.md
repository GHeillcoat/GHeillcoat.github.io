## 概述

激活函数（Activation Function）是神经网络中引入**非线性**的关键组件。如果没有激活函数，无论网络有多少层，整个模型都等价于一个线性变换（因为线性变换的复合仍是线性变换），无法拟合复杂的非线性函数。激活函数为每个神经元引入非线性变换，使神经网络具备通用近似能力（Universal Approximation Theorem）。激活函数的选择直接影响训练效率、梯度流动和模型性能。

## 为什么需要非线性

考虑一个 $L$ 层的前馈网络，如果每层都是纯线性变换：

$$ h^l = W^l h^{l-1} + b^l $$

则整个网络等价于一个单层线性变换：

$$ h^L = W^L \cdots W^1 x + \text{bias} = W_{eq} x + b_{eq} $$

无论多少层，都只能表示线性函数。激活函数 $\sigma$ 打破了这种线性：

$$ h^l = \sigma(W^l h^{l-1} + b^l) $$

## 主流的激活函数一览

### 经典激活函数

| 激活函数 | 公式 | 输出范围 | 导数 | 可微性 |
|---------|------|---------|------|--------|
| **Sigmoid** | $\sigma(x) = \frac{1}{1+e^{-x}}$ | (0, 1) | $\sigma(x)(1-\sigma(x))$ | 处处可微 |
| **Tanh** | $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | (-1, 1) | $1 - \tanh^2(x)$ | 处处可微 |
| **ReLU** | $\max(0, x)$ | [0, +$\infty$) | 0 或 1 | x=0 不可微 |
| **Leaky ReLU** | $\max(\alpha x, x)$, $\alpha$=0.01 | (-$\infty$, +$\infty$) | $\alpha$ 或 1 | x=0 不可微 |
| **PReLU** | $\max(\alpha x, x)$, $\alpha$ 可学习 | (-$\infty$, +$\infty$) | $\alpha$ 或 1 | x=0 不可微 |
| **ELU** | $x$ if $x>0$ else $\alpha(e^x - 1)$ | (-$\alpha$, +$\infty$) | 1 或 $\alpha e^x$ | 处处可微 |
| **SELU** | $\lambda \cdot$ ELU($x$), 自归一化 | (-$\lambda\alpha$, +$\infty$) | 缩放后的 ELU 导数 | 处处可微 |
| **GELU** | $x \cdot \Phi(x)$ | (-0.17, +$\infty$) | $\Phi(x) + x\phi(x)$ | 处处可微 |
| **Swish / SiLU** | $x \cdot \sigma(x)$ | (-0.28, +$\infty$) | $\sigma(x) + x\sigma(x)(1-\sigma(x))$ | 处处可微 |
| **Mish** | $x \cdot \tanh(\text{softplus}(x))$ | (-0.31, +$\infty$) | 较复杂 | 处处可微 |

### 专业激活函数

| 激活函数 | 公式概要 | 特点 | 主要应用 |
|---------|---------|------|---------|
| **Softmax** | $\frac{e^{x_i}}{\sum e^{x_j}}$ | 输出概率分布，归一化 | 多分类输出层 |
| **Softplus** | $\ln(1 + e^x)$ | ReLU 的平滑近似 | 极少使用 |
| **Maxout** | $\max(w_1^T x + b_1, w_2^T x + b_2)$ | 分段线性，通用近似 | 少量早期工作 |
| **SwiGLU** | $\text{Swish}(xW) \odot xV$ | 门控变体，LLaMA 使用 | 现代 LLM (LLaMA) |
| **ReGLU** | $\text{ReLU}(xW) \odot xV$ | GLU 门控 + ReLU | 部分 Transformer |
| **GeGLU** | $\text{GELU}(xW) \odot xV$ | GLU 门控 + GELU | 部分 Transformer |

## 激活函数选择指南

### 按架构选择

| 架构 | 推荐激活函数 | 原因 |
|------|------------|------|
| CNN (ResNet 系) | ReLU | 简单高效，梯度流动好 |
| CNN (EfficientNet 系) | Swish / SiLU | 平滑非单调，NAS 发现 |
| Transformer (BERT, GPT-2) | GELU | 平滑，训练稳定，BERT 验证 |
| Transformer (LLaMA 系) | SwiGLU | 门控变体，LLaMA 验证优秀 |
| RNN / LSTM | Tanh + Sigmoid | 门控机制需要 [-1,1] 或 (0,1) |
| GAN 生成器 | Leaky ReLU | 避免死亡神经元，保持梯度 |
| GAN 判别器 | Leaky ReLU | 同上 |
| 输出层（二分类） | Sigmoid | 输出 (0,1) 概率 |
| 输出层（多分类） | Softmax | 输出概率分布 |
| 输出层（回归） | 无 / Linear | 无界输出 |

### 按任务选择

| 任务 | 隐藏层推荐 | 说明 |
|------|----------|------|
| 图像分类 | ReLU / Swish | 成熟稳定 |
| 目标检测 | ReLU / SiLU | YOLO 系列用 SiLU |
| 语义分割 | ReLU | 标准选择 |
| 文本分类 | GELU | BERT 系标配 |
| 文本生成 | GELU / SwiGLU | GPT 用 GELU，LLaMA 用 SwiGLU |
| 语音识别 | GELU / ReLU | 取决于架构 |
| 强化学习 | ReLU / Tanh | 简单稳定 |

## 激活函数的进化史

| 年代 | 阶段 | 代表 | 特点 |
|------|------|------|------|
| 1940s-1980s | 早期 | Step, Sigmoid, Tanh | 生物学启发，易饱和 |
| 2010 | ReLU 革命 | ReLU | 简单有效，解决梯度消失，开启深度学习 |
| 2015 | ReLU 改进 | Leaky ReLU, PReLU, ELU | 解决死亡神经元 |
| 2016-2017 | 平滑非单调 | GELU, Swish | 处处可微，非单调，Transformer 标配 |
| 2020-2023 | 门控变体 | SwiGLU, GeGLU | 门控 + 激活的组合，LLM 新标准 |
| 2024-2026 | 自适应 | 动态激活、可学习激活 | 输入依赖的激活行为 |

## 2026 年趋势

1. **SwiGLU 成为 LLM 标配**：LLaMA-3, Qwen-2.5, DeepSeek-V3 均使用 SwiGLU
2. **GELU 在视觉 Transformer 中仍主流**：ViT, DINO, SAM 等
3. **激活函数与量化**：低精度推理（INT4/INT8）下激活函数的选择和校准
4. **动态激活函数**：根据输入特征自适应选择激活行为
