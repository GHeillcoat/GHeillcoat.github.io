## 2026-06-30

### E1：照抄用户原话不提炼
- 场景：用户用"像 Claude Code 读代码仓库"打比方解释搜索优先原则。我直接把"Claude Code"写进了规则。
- 错误：Claude Code 与 vault 操作没有必然关系，属于冗余引用。核心原则是"搜索定位 -> 只读匹配 -> 写"，不需要外部类比。
- 教训：用户给的例子是用来帮你**理解**的，不是用来往规则里**抄**的。提炼本质，扔掉比方。

### E2：引语张冠李戴
- 场景：将"nobody writes prompts anymore / the new job is to write loops"错误归于黄仁勋（NVIDIA CEO）。该引语实际来自 Boris Cherny（Anthropic Claude Code 负责人）和 Peter Steinberger（OpenClaw 创始人）。
- 错误：凭印象归因，未联网核实。黄仁勋 GTC 2026 确实讲了 AI 工程话题，但不是这句。
- 教训：名人引语必须先查证出处再引用。记不清谁说的就搜，搜不到就不写名字。
