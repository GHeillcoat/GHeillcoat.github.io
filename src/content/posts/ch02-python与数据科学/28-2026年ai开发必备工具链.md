AI 开发不是只有 Python。以下四个工具构成了 2026 年 AI 应用开发者的基础工具链，每个工具的定位一句话说清：

| 工具 | 一句话定位 | 你用它的场景 |
|---|---|---|
| **VS Code** | 最流行的代码编辑器，免费、插件丰富 | 写 Python 代码、管理项目文件、调试 |
| **GitHub Copilot / Claude Code** | AI 编程助手，帮你写代码、查 Bug、解释代码 | 你不会写的代码让它写，你写的代码让它检查，你读不懂的代码让它解释 |
| **Git / GitHub** | 版本管理，记录每次修改，随时回退 | 代码改崩了回退到昨天的版本；多人协作；备份到云端不怕丢 |
| **Docker** | 环境打包，让你的代码在任何机器上都能跑 | 把 Python 版本、依赖库、系统配置打包成一个镜像，同事或服务器直接拉下来就能跑，不用折腾环境 |

### 2.8.1 每个工具的具体用法

**VS Code**：装好 Python 插件和 Jupyter 插件后，可以直接在 VS Code 里编辑和运行 `.ipynb` 文件，比浏览器版 Jupyter 体验更好。2026 年推荐搭配 GitHub Copilot 插件，写代码效率提升 3-5 倍。

**GitHub Copilot / Claude Code**：2026 年的 AI 编程助手已经不只是"补全代码"了。你可以用自然语言描述需求，它生成完整代码；选中一段代码让它解释；报错了把错误信息贴给它，它帮你定位问题。**对零基础来说，AI 编程助手就是你随身携带的 Python 老师。**

**Git / GitHub**：你只需要掌握 5 个命令就能覆盖 90% 的场景：

```bash
git init          # 初始化一个仓库（项目文件夹）
git add .         # 暂存所有修改
git commit -m "描述"  # 提交一次快照
git push          # 推送到 GitHub 云端
git pull          # 从 GitHub 拉取最新版本
```

把 `git commit` 想象成"游戏存档"——每次完成一个小功能就存一次档，出问题了可以从最近的存档恢复。

**Docker**：如果你只在自己电脑上跑 AI 程序，暂时不需要 Docker。但当你需要把程序部署到服务器、或者和同事协作时，Docker 的价值就体现出来了——它消除了"我电脑上能跑，你电脑上怎么不行"的问题。2026 年 Docker 的替代品 Podman 和 OrbStack 也值得关注，但对新手来说 Docker 依然是首选。
