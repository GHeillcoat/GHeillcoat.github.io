传统 Python 学习路径（不要这么做）：
1. 花 3 个月学 Python 基础语法
2. 花 2 个月学面向对象编程
3. 花 1 个月学 Web 框架
4. 然后才开始学 AI

**2026 年推荐路径（按需学习，边用边学）：**

**第一周**：装好 Miniconda，学会 `pip install`。用 `requests` 成功调用一次 GPT/Claude API。目标：用 5 行代码拿到 AI 的回复。

**第二周**：学会用 Pandas 读取数据集，查看数据长什么样。目标：加载一个 CSV，算出每列的统计信息。

**第三周**：学会用 Matplotlib 画图。目标：把数据集的特征分布画出来，看看有没有异常。

**第四周**：学会用 NumPy 做简单的向量运算。目标：计算两个文本的 Embedding 相似度。

**之后**：遇到什么学什么。需要做微调就去学微调参数；需要做 RAG 就去学向量数据库；需要做 Agent 就去学工具调用。**不要预习，不要"系统地学完再开始"。**

这个学习路径的核心哲学：**你不需要成为 Python 专家，你只需要成为"能用 Python 操作 AI 工具"的人。** 这两者之间的差距，大概是学会修车和学会开车之间的差距。
