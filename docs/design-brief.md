# 视觉设计说明（设计工程师看这里）

站点：「墨痕 · inkwell」——一个古典淡雅、书卷气的中文博客。

- 开发服务器：**http://127.0.0.1:4321**（已在跑，不要另起服务器）
- 截图：`node scripts/shot.mjs "http://127.0.0.1:4321/" ".shots/xxx.png" --w=1440 --h=900 --theme=light --full`
  （`--mobile` 出 iPhone 尺寸，`--theme=dark` 出夜墨；会用本机 Edge headless，稳定、无需装浏览器）
- 截图目录 `.shots/`，可随意覆盖。

## 一、审美主旨

关键词：**宣纸、墨色、留白、克制、书卷气**。

不是「中式元素堆砌」，而是用现代排版手法做一本装帧考究的书：
比例准、细线讲究、留白大方、层级靠字重和空间而不是靠颜色和阴影。

风格基准（心理参照）：线装书的版面 / 苏州园林的借景与留白 / 京都侘寂 / 宋代瓷器的釉色。
避免：大红大紫、金色渐变、玻璃拟态、圆角大卡片、霓虹、emoji、夸张阴影、抖动动画、现代 SaaS 落地页感。

## 二、必须守住的规矩

1. **颜色克制**：整页 95% 是纸色与墨色。朱砂 `--cinnabar` 只用于印章、当前态、强调点，面积 < 1%。
   赭金 `--gold` 只用于极小的装饰（分隔点、渐变末端）。禁止大面积彩色块。
2. **线条细而少**：1px 才用 `var(--line)` / `var(--line-faint)`；分隔线优先用颜色区分而不是加粗。
3. **圆角极小**：卡片 2–3px，按钮胶囊除外（已有 pill 样式）。
4. **阴影像纸叠起**：`--shadow-1/2/lift` 已经很轻，不要加大。悬停位移 ≤ 3px。
5. **动效克制**：200–600ms，`--ease-ink` 曲线；只做透明度/位移/下划线展开；`prefers-reduced-motion` 全关。
6. **字体**：中文 `Noto Serif SC`（自托管切片），拉丁 `EB Garamond`，装饰 `--font-kai`（系统楷体），
   代码 `JetBrains Mono`。不要引入新字体，不要额外网络请求。
7. **中文排版**：正文首行缩进 2em、行距 1.95、两端对齐、标点挤压（已设置）；标题不缩进。
8. **性能**：只用 CSS，禁止外部图片/字体；`will-change` 只用在动画元素上；不要在滚动里做重排。
   现有样式总量约 60KB 未压缩，请控制增量。

## 三、当前截图里已经暴露的问题（请优先解决）

1. **首屏墨晕太重**：`.hero-bg` + `.ink-wash` 现在是一大团脏灰，压住了标题和精选卡片。
   目标：极淡的远山雾气——右下角为主，不遮字；整体 opacity ≤ 0.35；可用
   `/images/art/ink-mountains.svg` 做 mask（已有）或 `radial-gradient` 叠 `blur`。
   在暗色下同样要轻，不要发灰。
2. **首屏构图**：标题字号偏大、行距偏紧；右侧引文与印章挤在边缘相撞。
   重新分配栅格：左文右印（印章可只做装饰、避开引文），引文与正文基线对齐；
   可加入竖排小字（`.vertical-note`）作为点缀，但只出现一次。
3. **精选卡片**：没有题图时是空米色块 + 小字，观感空。请让「无题图」也成立：
   大字印（`.post-cover-glyph`）放大到 6–9rem、加淡墨晕/纸纹层次、被裁切的边缘，
   悬停时缓慢放大 + 阴影加深。卡片内部节奏（kicker/title/desc/foot）再收紧。
4. **页眉**：品牌印章里的「墨」字位置/字重需要视觉校准；导航字距、搜索胶囊的边框与内边距微调；
   滚动后加一道极淡的渐变遮罩会更高级。
5. **正文页**（`/posts/from-a-sheet-of-xuan-paper/`）需要逐项打磨：
   标题块（kicker/日期/元信息）层级、`h2` 前的朱砂竖线、引用块「」、代码块（顶栏、语言标签、复制按钮）、
   表格（表头线/行悬停）、脚注、KaTeX 行内公式基线、Mermaid 容器、图片说明、上下篇卡片。
6. **暗色「夜墨」**：现在是中性灰黑，缺墨的层次。要让深色纸有暖度（墨里透褐），
   朱砂在暗色下降低饱和；代码块、表格、卡片在暗色下都要重新确认对比度（正文 ≥ 7:1，次要文字 ≥ 4.5:1）。
7. **页脚**：品牌/格言/链接/版权的层级与留白；可加一枚极淡的竖排小字（`.vertical-note`）或云纹。
8. **移动端**（`--mobile`，390×844）：页眉、标题块、目录抽屉、批注面板、dock 按钮的间距与可达性（≥ 44px 触控）。

## 四、你的产出

- 只改 `src/styles/` 下的 CSS：`tokens.css`、`base.css`、`layout.css`、`components.css`、
  `prose.css`、`ornaments.css`、`pages.css`、`global.css`。
  **`fonts.css` 是脚本生成的，不要动**；**不要改 `.astro` 文件、不要改 `src/scripts/`**。
- 需要新增选择器/新 DOM 钩子时，先 `send_message` 给 lead 说明，由 lead 改模板。
- 允许重构 CSS 文件结构，但：
  - 保留 `global.css` 的 `@import` 顺序入口（可增删文件，但 `fonts.css` 必须最先）；
  - 保留所有现有 class 名（模板依赖），可以新增；
  - CSS 变量名保持稳定（`src/scripts/mermaid.ts` 会读取 `--paper` 等）。
- 交付标准：1440×900 与 390×844、明暗两套、首页 / 文章页 / 归档 / 标签 / 批注 / 关于 / 404 截图自检通过；
  每页看起来像被设计过，而不是默认样式。Console 无报错。
- 收尾时在 `docs/design-notes.md` 写 10–20 行：设计决策、动效清单、暗色策略、已知取舍。

## 五、协作约定

- 同一时间只允许一个人在跑截图（Edge headless 单实例没问题，但避免互相 `rm` 截图）。
- 发现 markup 有问题（缺 class、结构不适合排版）时，直接 `send_message` 给 lead，不要自己改 `.astro`。
- 与交互工程师（`interaction`）的边界：他只改 `src/scripts/`，浮层类（palette/toolbar/editor/lightbox/drawer）
  的 DOM 已存在，你只负责它们的样式；如需新结构找 lead。
