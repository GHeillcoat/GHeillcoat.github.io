# 视觉设计说明 · 墨痕

1. **纸墨系统**：墨分四层（`--ink` 焦墨 / `--ink-soft` / `--ink-mute` / `--ink-faint` 淡墨），线分三档（`--line` 1.31:1、`--line-strong` 1.6:1、`--line-faint` 1.1:1）；浅色纸上正文 15:1、次要 5.4:1、辅助 4.5:1，夜墨下 14.5 / 6.6 / 4.9。全部颜色都从纸色与墨色里取，朱砂只做印章、当前态、强调，面积 < 1%。
2. **版心**：页 1160px，正文 43rem（19px 中文约 36 字/行，接近 1.95 行距下的舒适上限），侧栏 16rem；首屏文案单独限到 34rem，让标题与引文之间有足够空白。
3. **首屏雾气**：不再用 blur 色团，改成「远山 SVG 当遮罩 + 墨色填充 + 三层 mask 复合」（横向往左淡出、山脚纵向淡出），所以 1440 宽下过渡到纸色没有边界；印章在右下单独占一块留白，不压引文。
4. **竖排小字**只出现一次：页脚右侧的「一卷终」，用纯 CSS 伪元素实现（`.vertical-note` 的样式同时保留给模板备用），移动端隐藏。
5. **精选卡**：无题图时用「大字印」——一个字落在右下、叠墨晕与一道纸光，字完整不裁切（裁切会读成 bug）；只有一张精选时改横排（图左文右），避免拉成一整条空纸。
6. **文章页公式**：`h2` 前只露一截朱砂竖线（2 × 0.92em），`h3` 用一颗赭金小点；标题层级全靠字号、字重与间距，没有彩色标题。
7. **引用块**：楷体 + 朱砂细线 + 极淡纸色渐变；去掉了旧的「」伪元素——正文里作者已经写了引号，叠上去会重影。脚注区加了「注」小标，正文中的上标只在 hover 时出血。
8. **代码块**：顶部 2.05rem 的纸色顶栏（1px 分隔），左侧语言标签（`data-language`），右侧常驻「复制」（0.55 透明度，hover 到 1）；正文里没有多余边框和重阴影。
9. **表格**：表头上下各一道 `--line-strong`，行间 `--line-faint`，首尾列去掉内边距让表格与正文左缘对齐，行悬停只加 60% 的 paper-sunken。
10. **夜墨**：纸色 `#171410` / `#1e1a14`（墨里透褐），朱砂降到 `#b97663`；墨晕改成极淡的月光（浅色墨），code/table/card 都单独校过对比度。精选卡在暗色里反相处理：有题图的一张压到 0.6 亮度并叠「上暗下纸」的纸色蒙版（实测平均亮度从 127 降到 86，页面纸 26），无题图的大字印改用月光色（screen），两种卡都不再像一块亮纸。
11. **首屏收口**：hero 底部留白降到 5rem，首节不再叠整块分节留白（`2rem`），1440 下「精选」比原来上移约 48px。
12. **动效清单**：`seal-press` 900ms（首屏印章按下）、`page-rise` 560ms（每次进入页面，仅 opacity/translateY）、`reveal` 640ms（滚动揭示，按索引 35–80ms 延迟）、下划线展开 460ms、卡片 hover `translateY(-2px)`、抽屉 250ms、`prefers-reduced-motion` 全关。
13. **触控**：移动端页眉 3.65rem、dock 2.75rem（44px）、导航项与页脚链接都 ≥ 44/32px；目录与批注合成一个右侧抽屉（`--header-h` 变量统一页眉高度）。
14. **一处结构性修正**：`.site-main > *` 的 `page-rise` 不能用 `animation-fill-mode: both`——动画结束后残留的 identity matrix 会让 `article.post` 成为 fixed 子元素的包含块，移动端抽屉会被定位进文章里。改成默认 fill 后正常。
15. **层叠约定**：页眉（sticky, 80）与悬浮坞（fixed, 70）都在 `.site-main`（z-index 2）之外，所以抽屉从页眉下沿开始、并在打开时收起 dock；这是当前 DOM 下最省事的解法。
16. **取舍**：全页纸纹是 `position: fixed`，整页截图里只覆盖首屏——这是截图工具的伪影，不是页面分层问题；代码块横向滚动时语言标签会跟着滚（`pre::after` 在滚动容器内）。
17. **Obsidian 展示层**（`src/styles/obsidian.css`，最后引入）：callout 用「一个字的小印记 + 2px 主色左线 + 极淡主色渐变底」，13 种类型只改三个局部变量（`--co-mark` / `--co-accent` / `--co-wash`），颜色只在 ink-mute / indigo / jade / gold / cinnabar 里取；主色 7%、朱砂类 4.5% 的极淡底，暗色降到 5–6%，折叠三角自绘（`summary::after`，prose 里的 ＋/－ 让位）。
18. **双链**读作「参见」：正文同色 + 点状下划线（`--ink-mute` 72%），hover 才出朱砂色与朱砂纸底；断链改虚线并退成淡墨。嵌入图与普通图片共用同一套圆角与 1px 描边；夜墨里正文图片压到 0.88 亮度（灯箱仍显示原图），免得一块白纸在黑夜里发亮。
19. **关联区块**：`关联 N` 标题 + 两张纸卡（反向链接 / 出链，行高 36px 可点）+ 局部图谱；没有双链时退化成虚线提示块。
20. **图谱面板 = 画布 + 一条细工具栏**：说明与 `＋ / － / 重置` 从画布上挪到下方工具栏（左说明、右控件，共用一条 1px 上边线），因此不再压住节点标签；工具条按钮桌面 32px、移动 44px，画布在移动端压到 400（整站）/ 320（局部）。
21. **体积**：手写 CSS 从约 77KB 增到约 125KB（其中 `obsidian.css` 约 22KB），生成文件 `fonts.css` 因重新按字切片从 315KB 降到 13KB，整站 CSS 体积仍大幅下降。没有新增网络请求（远山/云纹仍用现有 SVG 做 mask）。
